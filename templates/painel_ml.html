Como funciona (Modelo C — Conta única PoupáQui)
  • Conta central
    A rede PoupáQui tem uma única conta no Mercado Livre. Todos os produtos aparecem sob essa conta.
  • Produtos publicados
    Os produtos do catálogo PoupáQui são publicados no ML via API. O estoque é sincronizado automaticamente.
  • Pedido chega no ML
    O Mercado Livre notifica o sistema via webhook quando um pedido é feito.
  • Sistema atribui a loja
    O sistema geocodifica o CEP do comprador e encontra a loja mais próxima com estoque disponível.
  • Pedido no painel
    O pedido aparece automaticamente na lista de pedidos da loja atribuída, marcado com a badge Mercado Livre.
